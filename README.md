## Sobre

Pequeno jogo desenvolvido para praticar **lógica de programação, desenho em Canvas, eventos de teclado e atualização de estado no navegador**.

## Mecânicas implementadas

- Movimentação da cobrinha com as **setas do teclado**.
- Tabuleiro desenhado sobre uma grade de células.
- Comida posicionada aleatoriamente no tabuleiro.
- Crescimento da cobrinha e reprodução de som ao coletar comida.
- Movimento contínuo atualizado por um loop em JavaScript.

## Como jogar

1. Baixe ou clone o projeto.
2. Abra `index.html` em um navegador moderno.
3. Pressione uma das **setas direcionais** para começar a mover a cobrinha.

**Estado atual:** protótipo voltado às mecânicas básicas. A lógica de colisão com paredes/corpo, tela de fim de jogo e pontuação ainda não foi implementada.

**HTML · CSS · JavaScript · Canvas API**
